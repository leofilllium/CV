# Atria — описание проекта

Atria — мобильное приложение, которое объединяет тренировки, питание и отслеживание личного прогресса. Пользователь может вести дневник питания, искать продукты на русском, узбекском и английском языках, сохранять рецепты, составлять список покупок и записывать тренировки даже без подключения к сети. После восстановления связи данные синхронизируются с сервером.

Приложение также показывает динамику активности и питания, хранит зашифрованные фотографии прогресса и получает данные из Apple Health и Health Connect. Встроенный помощник строит ответы на основе записей пользователя. Сейчас он работает с тестовым провайдером модели; подключение реального ИИ-сервиса остаётся следующим этапом.

**Технологии:** Flutter, Dart, Riverpod, Drift, NestJS, Fastify, Drizzle, PostgreSQL, Redis и MinIO. Мобильный клиент отвечает за быстрый офлайн-сценарий, а сервер — за учётные записи, синхронизацию, хранение данных и логику помощника.
