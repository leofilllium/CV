## 3. Deep Dive: The 5 Flagship Systems

### 1. Study Ninja (AI EdTech Ecosystem)
- **Problem Solved:** Traditional learning platforms treat all students identically, leading to high drop-out rates.
- **Architectural Highlights:**
  - **Mobile:** Built with Flutter 3.x using **Clean Architecture** (strict separation of Domain UseCases, Data Repositories, and Presentation BLoCs).
  - **Streaming:** Engineered low-latency SSE (Server-Sent Events) streaming directly in Dio, parsing markdown tokens chunk-by-chunk for an instant conversational feel.
  - **Knowledge Graphs:** Utilized `@dagrejs/dagre` on the web client to render directed acyclic graphs representing student concept masteries.
- **Key Metrics:** 134 commits, sub-400ms token streaming latency, 0 UI jank during graph renders.

### 2. Sado AI: Universal Voice Call Center
- **Problem Solved:** Businesses in Uzbekistan lack automated customer support that speaks native Uzbek and understands product inventory.
- **Architectural Highlights:**
  - **Voice Pipeline:** Customer audio -> Uzbek Speech-to-Text (STT) -> RAG search over CSV product catalogs -> LLM reasoning -> Uzbek Text-to-Speech (TTS).
  - **Telephony Integration:** Configured Asterisk SIP PBX server and hardware cellular modem bridges for real telephony incoming/outgoing calls.
  - **Reliability:** Built with Playwright end-to-end integration tests and Telegram delivery fallbacks.

### 3. Safar One / Taxi Application
- **Problem Solved:** On-demand dispatching, routing, and real-time coordination between riders and drivers.
- **Architectural Highlights:**
  - **Real-Time Layer:** Bi-directional Socket.io server broadcasting geolocation coordinates every 1,000ms.
  - **Map Rendering:** Custom Flutter map overlays, smooth marker rotation along heading vectors, and animated route polylines.
  - **Backend Stability:** Express, Prisma ORM, connection pool management, and rate-limiting to prevent server exhaustion during peak dispatch events.

### 4. NikohUz (Matrimonial Platform)
- **Problem Solved:** Culturally sensitive matrimonial discovery and family communication in Uzbekistan.
- **Architectural Highlights:**
  - **Data Modeling:** Modeled 5 cultural conversation stages (`qabul`, `tanishuv`, `jiddiy`, `aloqa`, `oila`) in Prisma PostgreSQL schemas.
  - **Zero-Cost Geo Mapping:** Swapped expensive proprietary map SDKs for OpenStreetMap tile servers (`flutter_map` + `latlong2`), providing full countrywide coverage with zero API billing.
  - **Security & Storage:** Secure MinIO S3 object storage for profile photo moderation, Redis for brute-force rate-limiting, and Zod schema validation on every endpoint.

### 5. AI Lawyer Uzbekistan (`AI-UZ-Lawyer-Mobile` & Validator API)
- **Problem Solved:** High cost and complexity of standard contract validation for small businesses in Uzbekistan.
- **Architectural Highlights:**
  - **RAG Implementation:** Embedded Uzbek commercial codes and legal statutes into ChromaDB using LangChain.
  - **Client Experience:** Flutter BLoC client featuring 20+ specialized legal prompts, automated clause risk highlighting, and document generation.
