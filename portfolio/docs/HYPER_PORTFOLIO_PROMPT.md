Build an adventurous engineering portfolio that can be understood in 30 seconds and explored for ten minutes. The owner is Sherzod Akhmedov, a Middle Flutter and full-stack developer based in Tashkent. He is still studying Business Information Systems at WIUT. Preserve these facts. Never restore the removed claim about six apps, active users, or crash-free percentages.

Use an orbital expedition as the narrative device. The visual centerpiece must be a real, manipulable 3D object, with materials and lighting that suggest an engineered artifact. A single horizontal typographic moment connects the work gallery to a hands-on playground. Avoid a repeated grid of generic skill cards, decorative fake statistics, fabricated endorsements, and fake application screenshots.

Let the visitor do useful things. Filter projects by domain. Search the work using a command menu. Open a concise recruiter summary. Download the corrected PDF. Read project-specific challenge, contribution, outcome, and architecture pages. In a systems lab, let the visitor inspect how a mobile client, API, retrieval layer, and database connect. Add a brief optional space-navigation game with keyboard and touch controls and a reachable completion state.

Use Next.js App Router, TypeScript, Motion, React Three Fiber, native CSS tokens, and accessible dialog primitives. Generate both English and Russian routes. Preserve the project when switching language. Favor static generation, scoped state, dynamically loaded 3D, capped device pixel ratio, and self-hosted fonts. Every visible control must have a complete behavior. Every public-code link must point to a known public repository. Private work gets an honest description and an invitation to discuss it. There is no pretend AI chatbot, fake email submission, or hidden deployment dependency.

Deliver a reproducible npm lockfile, a passing production build and typecheck, browser-tested desktop/mobile flows, and Vercel root-directory instructions. Verify the game’s completion path, search, filters, case studies, locale switch, theme, reduced motion, CV download, and keyboard focus. Record real results rather than claiming unmeasured performance.
